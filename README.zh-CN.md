# Unlikely

**柠檬浓缩液 → 音乐 → 游戏读档 → 一部短片。**

两位手足清空旧厨房。一瓶柠檬浓缩液，成为短片构思《比例》的起点：同一句问话出现三次，每次改变一个选择。

## 这些联系，怎样变成一场戏

任务是：写一部只有**两位演员、一间厨房**的短片。

| 从哪里借来想法 | 用在这部短片的什么地方 |
| --- | --- |
| 柠檬浓缩液：同一份基底，可以调出不同比例 | 把同一个场景和问话留下，作为几次变化的共同材料。 |
| 音乐：反复的动机、休止符与呼应 | 在同一构图里，三次问“加多少水？”，通过回答、停顿和倒水，让含义发生变化。 |
| 游戏读档：回到同一起点，改变一次选择 | 再次回到这个场面，改变谁掌握水壶。借用的是变化结构，不必把故事写成真的时间循环。 |

《比例》中，水壶先在发号施令的人手里，接着被两人争抢，最后放到桌中央。结尾留下两杯分别标着 **1:2** 和 **1:5** 的饮料，两人保留各自的版本。

Unlikely 是一个开源创意探索工具：把这样的联系展开成完整网络，提供每条连线的理由，**由你决定哪些联系值得进入作品。**

## 先走一条路线，再改成你的

1. **打开完整网络。** 精选写作案例直接可看，不需要等待模型生成。
2. **点开一条联系。** 查看节点或连线，理解这条关系能为任务带来什么。
3. **决定留下什么。** 先试一条附完整结果的预设路线，也可以自己添加、重排或移除节点，再导出 Markdown、JSON 或 SVG 路线卡。

尚未建立的关系会明确显示。系统可以沿已有连线建议衔接路径，由你决定是否加入。主打路线带有预设结果，也可以另选路线继续探索。

## 写作、产品、商业，都可以从同一个起点出发

三个完整案例都从**柠檬浓缩液**出发，各有一张完整网络，以及两条附预设结果的路线。

| 任务 | 可以继续发展的方向 |
| --- | --- |
| 写一部只有两位演员和一间厨房的短片 | 《比例》：同一句问话，从控制走向共同选择。 |
| 设计一个帮助创作者返回工作的产品 | 用“上下文胶囊”保留一个决定背后的意图和理由。 |
| 为社区咖啡店探索低成本服务 | 在两个清闲下午试办“二十分钟调味站”。 |

这些是人工编排的精选案例，不是实时生成。完整匹配预设路线时，会显示对应结果；模型服务不可用时，其他路线仅整理选中的节点和已有关系，不会生成新的方案。

## 换成你自己的任务

输入写作、产品、商业，或其他创意任务，选填已有灵感与限制。公共试用无需账号，也不需要访客填写自己的 API key。

自由输入的生成有额度限制：默认每个匿名会话和每个 IP 地址**每个 UTC 日各有三次模型操作额度**，生成网络、延展和整理主线共用，按较少余额执行；同时受全局用量、并发和月度预算限制。**精选案例不消耗该额度。**

已使用 Kimi K2.6 完成一次真实公开网页生成；真实延展和整理尚未验证，详见[验证记录](docs/verification-v0.3.2.md)。服务不可用或额度用完时，已有内容和精选案例仍可继续查看。更多说明见[公共试用限制与数据处理](docs/public-trial.md)。

## 高级选项：使用自己的模型

主动打开可选的模型设置，填写 API 基础地址、模型名称和 API key，然后**测试并连接**。

- 服务需兼容 OpenAI `/chat/completions`、Bearer 认证、通过 `response_format` 请求 JSON 对象输出，以及浏览器跨域请求（CORS）。
- 连接测试会发起模型请求；测试、生成、延展和整理都可能产生**你自己的服务商账户费用**，适用时也包含思考过程计费。
- 浏览器直接请求你指定的服务商。如果服务商禁止浏览器直连，可以使用下方的本地服务器方式。

高级 BYOK 接口已进行 mock 测试。上述公共生成验证不代表浏览器 BYOK、其他服务商，或真实延展与整理操作已经通过验证。连接测试成功，也不代表全部操作都能完成。

## 本地运行

需要 **Node.js 22.9.0 或更新版本**，本地应用无需安装依赖。

```sh
git clone https://github.com/rre37826-source/unlikely.git
cd unlikely
npm start
```

打开 **[http://127.0.0.1:4317](http://127.0.0.1:4317)**。如需通过本地服务器调用自己的模型：

```sh
cp .env.example .env
```

在 `.env` 填写 `MODEL_BASE_URL`、`MODEL_API_KEY` 和 `MODEL_NAME`，然后重启 `npm start`。服务器会在基础地址后追加 `/chat/completions`。此方式绕开浏览器 CORS 限制，但仍需满足服务兼容性要求，并由自己的服务商账户承担费用。

本地服务器只监听 `127.0.0.1`。公共试用使用独立网关和 D1 配额存储，本地服务器不是公开部署的生产代理。前端继续由 GitHub Pages 托管。

## 数据与内容

| 内容 | 保存或发送位置 |
| --- | --- |
| 任务、网络、路线和草案 | 已保存的项目使用本机 `localStorage`；示例预览需点击**保存这张地图**。也可导出 JSON 保留副本。 |
| 公共试用内容 | 经网关发送给固定模型服务商；网关不持久化任务或图谱内容。 |
| 公共试用配额数据 | D1 保存计数及请求记录，配额标识经 HMAC 派生，不在其中保存原始 IP。 |
| 可选网页模型设置 | 密钥、地址和模型仅保留在页面内存，刷新清除，不写入存储或导出文件。 |
| 服务端模型凭据 | 留在服务器，不发送到浏览器。 |

应用没有产品分析埋点和用户账号；托管平台及模型服务商可能保留各自的服务日志。本机浏览器保存不会跨设备同步，清除站点数据会删除探索记录。公共试用限流与产品分析属于不同用途。

内容区分**预设案例、模型生成和导入项目**；连线区分**关联、类比和假设**。这些标记说明来源和用途，不代表准确性或价值已经得到证明。

## 开发与贡献

使用原生 HTML、CSS、JavaScript，以及 Node 内置本地服务器和测试工具，支持中英切换。

```sh
npm test
npm run check
```

- `public/app.mjs`：任务入口、网络探索、路线、本机保存和导出。
- `public/core.mjs`、`public/layout.mjs`：图校验、路线逻辑，以及支持 1–16 个分区、最多 150 个节点的布局。
- `public/model-client.mjs`、`public/model-protocol.mjs`：模型请求及共享操作规则。
- `public/examples.mjs`：双语精选案例与完整路线。
- `trial/index.mjs`：公共网关处理函数，需要 D1 和运营者配置。
- `server.mjs`：本地服务器与可选私有模型接口。
