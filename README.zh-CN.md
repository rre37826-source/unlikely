# Unlikely

**把任务展开成可能性的地图，由你选出自己的创意路线。**

一个开源创意探索工具，面向写作、产品、商业，以及你带来的具体任务。先看见全景网络，再追问意外连接的理由，把值得留下的关系选成主线。

**[打开演示](https://rre37826-source.github.io/unlikely/)** · [本地运行](#本地运行) · [English](README.md)

![Unlikely 的全景联想网络与用户选出的创意路线](docs/demo.gif)

- **先看全貌，再选方向。** 不同领域的线索同时展开，沿着让你感兴趣的关系探索。
- **看见连接的理由。** 每条连线都有解释，类比与假设保留明确标记。
- **由人决定留下什么。** 节点可以加入、重排、移除；路线可以导出为 Markdown、JSON 或 SVG 卡片。

在线演示使用**人工编排的精选案例，不是实时 AI 生成**，无需账号或 API key。可选的本地模型接口支持请求生成和延展网络；目前只经过 mock 测试，**尚未使用真实模型服务验证**。

## 同一个起点，三种不同任务

三个案例都从**柠檬浓缩液**出发，每个案例包含六个分区、31 个节点和两条附完整结果的预设路线。

| 任务 | 网络中的一条路线 | 可以继续发展的方向 |
| --- | --- | --- |
| 写一部八分钟短片 | 浓缩 → 数据压缩 → 被略去的细节 → 配方 | 两个手足向旧家告别，最终留下两种不同版本的家庭饮料。 |
| 探索帮助创作者返回工作的产品 | 压缩 → 省略 → 缺失的上下文 | 用“上下文胶囊”保留一个决定背后的意图和理由。 |
| 为社区咖啡店设计低成本服务实验 | 小容器 → 有限道具栏 → 简单规则 → 碰面点 | 在两个清闲下午试办“二十分钟调味站”。 |

这些是用于探索的创意示例。产品价值和商业需求仍需验证，不代表已经取得相应效果。

## 开始探索

1. 打开演示，选择写作、产品或商业案例。**20 秒演示**会带你走完其中一条精选路线。
2. 点击节点或连线，查看内容及关系解释。
3. 把有感觉的节点加入自己的路线，随时调整顺序或移除。
4. 如果相邻节点没有直接关系，路线会显示尚待探索的缺口。**寻找已有的连接路径**会在当前图中找路，先展示建议，再由你决定是否保留。路径短，不意味着创意一定好。
5. 点击**整理成创意主线**，导出结果或继续探索。

未接入模型时，完整匹配六条预设路线之一，会显示对应的人工编排结果。其他路线仅整理你选中的节点及已有关系，**不会冒充新生成的创意方案**；尚未连通的部分也会明确保留。

## 本地运行

需要 **Node.js 22.9.0 或更新版本**。使用原生 HTML、CSS、JavaScript，以及 Node 内置服务器和测试工具，无需安装依赖。

```sh
git clone https://github.com/rre37826-source/unlikely.git
cd unlikely
npm start
```

打开 **[http://127.0.0.1:4317](http://127.0.0.1:4317)**，即可体验精选案例。

```sh
npm test
npm run check
```

## 可选：接入自己的模型

复制配置模板：

```sh
cp .env.example .env
```

填写本地 `.env`，再重启 `npm start`：

```dotenv
MODEL_BASE_URL=https://your-provider.example/v1
MODEL_API_KEY=your-local-key
MODEL_NAME=your-model-name
PORT=4317
```

服务器会在基础地址后追加 `/chat/completions`。接口需要兼容 OpenAI chat completions 的请求和响应格式、Bearer 认证，以及通过 `response_format` 请求 JSON 对象输出。能否使用取决于具体模型服务；**当前仅完成模拟响应测试，尚未接入真实服务验证。**

配置后，可以在本地请求：

- **生成网络：** 围绕具体任务和灵感种子展开关系。
- **延展节点：** 深入、类比、反转前提，或连接其他分区。
- **整理主线：** 基于人选定的路线形成草案，并列出缺失关系和假设。

请把受众、限制条件一起写进任务描述。程序会校验返回图的结构和连通性，但这些检查不能证明内容真实或创意有效。完整匹配预设路线时，仍显示带明确标记的精选结果。

## 数据保存与发送

| 使用方式 | 保存位置与模型请求 |
| --- | --- |
| 在线静态演示 | 浏览器允许时，探索记录保存在本机浏览器的 `localStorage`；不发送模型请求。 |
| 未配置模型的本地应用 | 同样使用精选案例和本机浏览器保存。 |
| 已配置模型的本地应用 | 主动请求生成、延展或整理时，本地服务器会把任务及相关网络、路线内容发送给你配置的服务商。 |

API key 留在本地服务器环境变量中，不会传到浏览器。**模型处理是否留在本机，取决于你配置的服务地址**；远程服务商会收到请求内容。接口也可指向本机兼容服务，但当前未验证这一配置。

本版本没有应用分析埋点或账号系统；静态托管与模型服务商可能保留各自的服务日志。本机浏览器保存不等于备份，也不会跨设备同步。建议导出 JSON 保留可迁移副本；清除站点浏览器数据会删除本机保存的状态。

内置服务器仅监听 `127.0.0.1`，只接受通过本机地址进入的请求，**不适合作为公开部署的生产模型代理**。GitHub Pages 只提供精选案例的静态演示。

## 内容来源与关系标记

- **预设案例：** 人工编排的示例，不是本次实时生成。
- **模型生成：** 需要由人判断，并独立核实涉及事实的内容。
- **导入项目：** 来源未经独立验证；导入不会保留“来源可信”的承诺。

连线区分**关联、类比、假设**。这些标记说明关系在探索中的作用，不是证据评级。创作类比不能证明因果关系，模型和导入内容中的事实也需要核查。

## 开发与贡献

| 文件 | 作用 |
| --- | --- |
| `public/app.mjs` | 网络交互、路线编辑、本机保存和导出 |
| `public/core.mjs` | 图校验、路线逻辑、已有路径搜索和 Markdown 导出 |
| `public/examples.mjs` | 双语案例、连线解释及完整预设路线 |
| `server.mjs` | 本地静态服务器与可选模型接口 |

应用支持中英切换。JSON 导入导出保留网络和选定路线，Markdown 包含关系解释，SVG 可用于分享路线卡片。

高质量案例是项目的重要组成部分。欢迎贡献一个具体任务、一组意外但说得通的连接，以及一条可以完整走通的路线。详见 [CONTRIBUTING.md](CONTRIBUTING.md)。
